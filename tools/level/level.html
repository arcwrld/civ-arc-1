level

Drop a text file on this page and it tells you the shape of the file: whether it uses Windows line endings, whether it carries an invisible byte order mark, whether it is really UTF-8, whether it ends with a newline, and whether it has trailing spaces or tab indentation. It then shows you the levelled copy, line by line, and you decide whether to keep it.

Written by plane in arc 1. Nothing leaves your machine: this page has no server, no upload and no network of any kind. Your file is never changed unless you ask for the levelled copy and save it yourself. The command line version of the same rules is node tools/level/level.js --help.

    What level checks

    crlfthe file uses CRLF (Windows) or bare CR (classic Mac) line endings
    bomthe file starts with a UTF-8 byte order mark
    encodingthe file is not valid UTF-8
    final-newlinethe file does not end with a newline
    trailing-spacea line ends in spaces or tabs
    tabsa line is indented with a tab character

    Every one of these can be settled by looking at bytes. None of them is an opinion about what the file should contain. Level has no opinion about line length, quote style, naming, indentation width, or anything else that is a matter of taste.

    How to use it on a real file

    Drop notes.txt on the page and it shows you what is wrong with the shape of the file and what the levelled copy would be. Press Save the levelled copy and your browser puts a new file in your downloads. Compare the two, and if you are happy, replace the original yourself. Level never edits the file you gave it.

    On the command line the same rules can fix the file for you, if you ask:

    node tools/level/level.js check notes.txt
node tools/level/level.js fix   notes.txt --write

    Limits

    1. Level checks the shape of a text file. It does not check what the text says, and it does not know what the file is for.
    2. A file that is not valid UTF-8 is reported and left alone. Level will not guess what the bytes were meant to be.
    3. Tabs are expanded to the next tab stop, four columns wide. If your project uses a different width, the indentation will not match its style, though the tabs will be gone.
    4. Level does not look inside a file it is given. It does not follow includes, does not read a project file, and does not care which language the file is in.
    5. The browser page reads the whole file into memory. It is a tool for documents, not for disk images.
    6. The page can only read files you pick, and can only save the levelled copy by asking your browser to save it. It cannot write beside your file. The command line tool can, if you ask it to.
