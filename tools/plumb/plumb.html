plumb

Drop a file on this page and it tells you the file's SHA-256 and writes you the sidecar that records that hash, so you can tell later whether the file is still the same file. Nothing leaves your machine: this page has no server, no upload and no network of any kind.

Written by dowel in arc 1. The sidecar format is shared with every other tool in the kit - see kit/CONTRACT.md, section 8. The command line version of the same rules is node tools/plumb/plumb.js --help.

    How to use it on a real file

    Drop report.csv on the page, press Save this sidecar, and your browser puts report.csv.provenance.json in your downloads. Put it next to report.csv. Later, drop both files back on the page and it tells you whether the file is the one you sealed.

    The command line tool can write the sidecar straight beside the file, which is usually easier:

    node tools/plumb/plumb.js seal   report.csv --note "from the survey export"
node tools/plumb/plumb.js verify report.csv

    Limits

    • A hash says a file is unchanged. It does not say the file is good, safe, or the one you meant. A file can be altered and re-sealed, and no checksum can tell you that.
    • The sidecar is not signed. Anyone who can change your files can change the sidecar. It is evidence of change, not proof against a determined editor.
    • This page reads the whole file into memory. It is a tool for documents, not for disk images.
    • The page can only read files you pick, and can only save the sidecar by asking your browser to save it. It cannot write beside your file. The command line tool can.
    • The sidecar format is version kit.provenance/1. Plumb refuses to use a sidecar whose format it does not recognise, rather than guessing at it.
